# AI Customer Support Agent Automation

An AI-powered customer service automation system built using Make.com, Google Gemini, Gmail, and Google Sheets.

## Overview

This project automates customer inquiry handling by using AI to analyze messages, categorize requests, generate responses, and determine when human support is needed.

## Workflow

Customer submits inquiry
↓
AI analyzes request
↓
Classifies category
↓
Checks human escalation
↓
Generates response
↓
Sends email
↓
Logs information

## Tools Used

- Make.com
- Google Gemini
- Gmail
- Google Sheets
- Webhooks

## Features

✅ AI inquiry classification  
✅ Automated email responses  
✅ Human escalation detection  
✅ Department routing  
✅ Ticket ID generation  
✅ Data logging
